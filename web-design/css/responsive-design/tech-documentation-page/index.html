HTML

HTML stands for HyperText Markup Language and is the standard code used to structure and display content on a web page.

It is not a programming language; rather, it is a markup language that uses a system of tags to define the individual structural blocks of a website, such as text paragraphs, links, headings, and images.

You can read more comprehensive guides on platforms like the MDN Web Docs HTML Guide or the W3Schools HTML Introduction to see how it operates.

CSS

CSS stands for Cascading Style Sheets. It is a style sheet language used to control the visual presentation, formatting, and layout of a web document.

Developers use CSS to transform plain text into a modern user experience. It handles:

  • Aesthetics: Defining text colors, custom typography, and page backgrounds.
  • Layouts: Structuring web content via multi-column grid layouts, padding, and alignment.
  • Responsiveness: Scaling websites smoothly so they display correctly on desktops, tablets, and smartphones.
  • Interactivity: Adding hover states, animations, transitions, and dynamic effects.

JavaScript

is a lightweight, cross-platform programming language primarily used to make web pages interactive. It is one of the core technologies of the World Wide Web (alongside HTML and CSS), enabling dynamic content updates, web page animations, interactive maps, and complex multimedia controls.

To understand JavaScript, it helps to see how it works alongside the other two foundational languages of the web:

  • HTML (HyperText Markup Language): Defines the structure and raw content of the page, like paragraphs, headings, and images.
  • CSS (Cascading Style Sheets): Handles the styling and design, including fonts, colors, and layout configurations.
  • JavaScript: Adds the behavior and logic, transforming static content into an interactive user experience.

React

NodeJS

Node.js is a free, open-source, cross-platform JavaScript runtime environment that allows developers to execute JavaScript code outside of a web browser.

In web development, a URL fragment is the part starting with a # symbol. Browsers do not send this fragment to Node.js HTTP servers by default. However, if you are parsing full URL strings inside Node.js, you can easily extract the fragment using the built-in URL module

// Using Node.js built-in URL API
const { URL } = require('url');
const myUrl = new URL('https://example.com');
// Access the fragment (hash)
console.log(myUrl.hash); 
// Output: #settings-tab
