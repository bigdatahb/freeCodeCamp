HTML 语义元素

使用 HTML 语义元素很重要，它不仅能提升我们的开发体验，更重要的是无障碍体验和SEO，搜索引擎能够通过语义元素看懂我们的文档结构

常用的语义元素

语义化（semantic）HTML侧重内容结构，表现型（presentational）HTML侧重外观。常用的语义化HTML元素有：<main>, <header>, <footer>, <section>, <article>, <aside>, <nav>等

<em>, <strong> and <dl>

em 和 strong 除了特定样式外，还着重强调文本的重要性（语义）

description list 适合呈现键值对形式的相关信息
